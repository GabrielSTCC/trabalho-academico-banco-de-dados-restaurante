# Trabalho Acadêmico de Banco de Dados — Restaurante

Sistema de gestão de restaurante desenvolvido para a disciplina de Banco de Dados.

## Conteúdo

- Scripts SQL (DDL, DML e relatórios)
- CRUD web em PHP (tabela Cliente)
- Diagramas conceitual e lógico
- Documentação completa em `docs/`

## Requisitos

- MySQL 8.0
- PHP 8.x com extensão mysqli

## Configuração

1. Copie `config.example.php` para `config.php` e ajuste a senha do MySQL
2. Execute `.\setup.ps1` para criar o banco
3. Execute `.\iniciar.ps1` e acesse `http://localhost:8000`
